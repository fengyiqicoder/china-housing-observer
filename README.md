# 中国楼市 · 城市观察

一个零依赖的纯前端单页面，展示中国 64 个主要城市（一线城市、直辖市、副省级城市/计划单列市、省会城市，以及各省代表性地级市——每个省份至少收录两个城市）的：

- **平均房价**（二手住宅挂牌均价，元/㎡）
- **平均月租**（整租套均月租金，元/月）
- **平均工资**（城镇单位就业人员税前月薪，元/月）

并对照三项国际通行标准：

| 指标 | 计算方式 | 国际标准 |
| --- | --- | --- |
| 房价收入比 | 房价 × 90㎡ ÷ 双职工家庭年收入 | 合理区间 3–6 倍（世界银行 / 联合国人居署常引） |
| 租售比 | 月租金 ÷（房价 × 60㎡），记作 1:N | 合理区间 1:200–1:300（约 17–25 年回本） |
| 房租收入比 | 月租金 ÷ 月薪 | 警戒线 ≤ 30% |

## 使用

直接双击打开 `index.html` 即可，无需构建、无需服务器。

## 更新数据

编辑 `data.js` 中的数字（字段口径见文件内注释），刷新页面即可生效。

## 页面结构

数据看板式布局，一个城市一个卡片框：

- **顶部图例条** — 三项国际标准的说明（图标 + 标准值）
- **筛选与排序** — 按分组筛选（全部/一线/直辖市/副省级/省会/地级），按任意指标升降序排序
- **64 张城市卡片** — 每张卡片包含：
  - 城市名、分组徽章、当前排序名次
  - 房价 / 月租 / 工资三项数据（带图标），每项下方有相对全部城市最高值的彩色对比条
  - 三项国际指标小量表：黑色刻度为标准线，绿色达标、红色超标
- **世界参照卡** — 纽约、伦敦、东京、新加坡四张完整卡片，与中国城市相同的字段（房价/月租/工资，按当期汇率折合人民币的估算值）与指标口径

## 数据说明

默认数据为 2025 年估算示例值，仅供演示。实际数值请以国家统计局、各地统计局及贝壳、诸葛找房等平台最新发布为准。
